# Souzas Dev — Frontend

Frontend do site da **Souzas Dev**, desenvolvido em HTML, CSS e JavaScript.

## Estrutura

O repositório reúne as páginas públicas e administrativas da interface, além dos conteúdos e assets do site.

Principais áreas:

- `index.html` — página inicial;
- `sobre.html` — apresentação;
- `servicos.html` e `servicos/` — serviços;
- `cases/` — cases e demonstrações;
- `conteudos/` — conteúdos publicados;
- `admin.html` e `login.html` — interface administrativa;
- `css/`, `js/` e `assets/` — estilos, scripts e recursos visuais;
- `.github/` — automações do repositório.
