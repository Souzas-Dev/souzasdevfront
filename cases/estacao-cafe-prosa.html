Apresentação

Uma cafeteria fictícia com experiência digital real.

A Estação Café & Prosa é a evolução da primeira demo Cafeteria Conceito. A nova versão amplia a identidade visual, a narrativa editorial e a consulta de produtos em uma experiência responsiva.

Desafio

Criar uma página que transmitisse a sensação de uma cafeteria moderna e acolhedora sem excesso de elementos, cores ou animações.

O cardápio precisava ser fácil de consultar e funcionar bem em diferentes tamanhos de tela.

Solução

Foi desenvolvida uma interface minimalista, com tipografia editorial, paleta inspirada em tons de café e bastante espaço visual.

O cardápio é renderizado dinamicamente com JavaScript e pode ser filtrado por categorias.

Direção visual

A composição utiliza tons suaves, contraste confortável, imagens de produtos e componentes discretos para manter a leitura agradável.

A identidade foi pensada exclusivamente para esta demonstração conceitual.

Principais funcionalidades

Recursos pensados para consulta rápida e intuitiva.

A navegação e o cardápio foram estruturados para funcionar com clareza em desktop, tablet e celular.

Cardápio digital

  • Produtos renderizados com JavaScript
  • Filtros por categoria
  • Contador de resultados
  • Preços formatados em real brasileiro
  • Tratamento para imagens indisponíveis

Experiência responsiva

  • Desenvolvimento mobile-first
  • Menu adaptado para dispositivos móveis
  • Navegação por âncoras
  • Layout fluido a partir de 320 px
  • Imagens armazenadas e otimizadas localmente

Conteúdo institucional

  • Apresentação da cafeteria fictícia
  • Informações sobre o conceito
  • Localização meramente ilustrativa
  • Mapa construído com elementos visuais
  • Avisos claros sobre o caráter conceitual

A versão atual utiliza Next.js, React e TypeScript, com exportação estática, controle de qualidade e publicação automatizada pelo GitHub Actions.

Evolução do projeto

Da Cafeteria Conceito à Estação Café & Prosa.

O projeto foi preservado como registro da primeira versão e recebeu uma evolução técnica e visual em 2026. A nova etapa passou a se chamar Estação Café & Prosa.

Primeira versão

A Cafeteria Conceito foi desenvolvida originalmente com HTML, CSS e JavaScript, apresentando conteúdo institucional e um cardápio digital responsivo.

Evolução em 2026

A aplicação foi reconstruída com Next.js, React e TypeScript, recebeu uma nova identidade editorial, catálogo com busca e filtros e componentes mais organizados para manutenção.

Publicação atual

A versão atual utiliza exportação estática, GitHub Actions e GitHub Pages. O projeto continua sendo uma demonstração conceitual fictícia criada para o portfólio da Souzas Dev.

Resultado

Uma demonstração leve, responsiva e profissional.

O resultado é uma experiência preparada para representar uma solução real que poderia ser adaptada para cafeterias, restaurantes e outros negócios do setor alimentício.

A demonstração mostra como identidade visual, organização de conteúdo e interatividade podem trabalhar juntas sem depender de frameworks externos.
