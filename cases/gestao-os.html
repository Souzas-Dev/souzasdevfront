Gestão OS

Uma experiência operacional para clientes, orçamentos e serviços.

Uma aplicação web fictícia criada para explorar como pequenas equipes podem organizar o ciclo de atendimento em uma interface clara, navegável e fácil de apresentar.

01

Visão geral

Dashboard e módulos para acompanhar clientes, propostas e execução de serviços.

02

Desafio

Criar uma demo que parecesse um produto utilizável sem depender de dados reais ou backend.

03

Solução

Interface estática com interações temporárias, filtros, CRUD local e restauração da demonstração.

O que foi desenvolvido

Uma operação fictícia com fluxo completo.

A demo foi pensada para que quem visita o portfólio possa testar a experiência livremente, sem cadastro e sem deixar dados persistidos.

Experiência de produto

  • Dashboard com indicadores operacionais
  • Clientes, orçamentos e ordens de serviço
  • Busca e filtro por status
  • Criação, edição e exclusão temporárias
  • Estado vazio e feedback de ações
  • Botão para restaurar a demonstração

Decisões técnicas

  • Next.js com exportação estática
  • React e TypeScript
  • CSS Modules sem biblioteca visual externa
  • Dados fictícios fixos no código
  • Estado somente em memória
  • Deploy preparado para Vercel

Aprendizados

Escopo definido para uma demonstração honesta.

O projeto separa o que precisa ser convincente em uma peça de portfólio do que faria parte de uma evolução de produto, como autenticação, API e persistência real.

O que a demo mostra

  • Hierarquia visual para dados de negócio
  • Componentização de tabelas e formulários
  • Responsividade para diferentes telas
  • Fluxos de interação fáceis de testar

Próxima evolução

  • API e banco de dados
  • Autenticação e permissões
  • Integrações de atendimento
  • Testes de integração
